# 🚲 Bike Landing Page

A fully responsive landing page for a bike shop, 
built with clean semantic HTML and modular SCSS 
following BEM methodology.

## 🌐 Live Demo
[View Live](https://your-demo-link.com)

## ✨ Features
- Fully responsive layout (mobile, tablet, desktop)
- Smooth scroll and CSS animations
- Interactive burger menu with CSS-only toggle
- Hover effects on products and navigation
- Contact form with styled inputs and focus states
- Product comparison section
- Sticky footer with background image

## 🛠 Technologies
- HTML5
- SCSS (BEM methodology)
- Parcel (bundler)

## 🚀 Run Locally

Clone the project:
```bash
git clone https://github.com/your-username/bike-landing
cd bike-landing
```

Install dependencies and start:
```bash
npm install
npm start
```

Open **http://localhost:1234** in your browser.

## 📦 Deploy
```bash
npm run deploy
```
